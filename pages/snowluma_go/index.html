插件配置

运行方式
远程打开 WebUI 需要监听 0.0.0.0，保存后重启 SnowLuma 生效。
账号与 AstrBot
无桌面服务器会自动启动 Xvfb，并可在「QQ 登录」里直接查看二维码截图；VNC 是可选的备用方式。
留空密码时 x11vnc 只监听 127.0.0.1，可通过 SSH 隧道访问；填写密码后允许局域网连接。
留空表示不修改。接管已有 SnowLuma 时，填写它当前的 WebUI 密码； 可在 SnowLuma 启动日志中搜索 initial credentials 找到初始密码。
自动化
自启动只会在本插件确认已安装后执行；安装完成会立即自动启动一次（可关闭）。
维护与帮助
安装、更新、卸载与下载镜像在「下载与安装」里；Linux 依赖包含 fluxbox / xvfb / x11vnc / dbus-x11 等。 QQ 登录界面空白或不显示时，可点「修复 QQ 登录界面」：恢复被 NapCat 改掉的启动入口并回滚热更新。

下载与安装 SnowLuma

下载源
可直接输入自定义前缀，或点击右侧箭头选择内置镜像。选择后无需保存，下一次下载立即使用； 失败时仍会按 NapCat_Go 的镜像顺序自动回退。
下载完成后会自动检查 Linux 依赖（xvfb / x11vnc / fluxbox / dbus-x11 / scrot）； 缺少时自动安装，未配置 sudo 密码则报错并跳过安装。
版本与发行包
安装会替换程序文件，但保留 config/、data/ 等用户数据。
